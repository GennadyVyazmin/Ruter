# Установка

## Требования

- Debian или Ubuntu;
- root-доступ;
- рабочий основной сетевой интерфейс;
- VLESS REALITY-ссылка или URL подписки.

## Установка

```bash
curl -fsSL \
  'https://raw.githubusercontent.com/GennadyVyazmin/Ruter/refs/heads/main/install.sh' \
  -o /tmp/ruter-install.sh

chmod +x /tmp/ruter-install.sh
sudo /tmp/ruter-install.sh
```

После установки открой меню:

```bash
sudo ruter
```
