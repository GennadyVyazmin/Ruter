# Маршрутизация

Ruter поддерживает четыре режима:

1. одно устройство;
2. несколько устройств;
3. вся локальная сеть;
4. маршрутизация отключена.

Изменить режим:

```bash
sudo ruter route
```

Для policy routing используется отдельная таблица маршрутизации. Сама VM получает более приоритетное правило через таблицу `main`, чтобы не терять интернет при отказе VPN.
