# Диагностика

Основная команда:

```bash
sudo ruter doctor
```

Она проверяет:

- наличие настроек;
- состояние sing-box;
- состояние `ruter-route.service`;
- корректность конфигурации;
- LAN- и TUN-интерфейсы;
- DNS;
- синхронизацию времени;
- правила `ip rule`;
- таблицу маршрутизации;
- SOCKS/mixed inbound;
- последние ошибки журнала.

Если обнаружено сообщение `reality verification failed`, проверь на сервере REALITY параметр минимальной версии клиента. Для актуальных версий Xray-core в рабочей конфигурации использовалось значение `1.0.0`.
