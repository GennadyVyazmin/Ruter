# Changelog

## 2.0.2 — 2026-07-28

- Исправлено правило nftables: CIDR больше не передаётся парсеру nft как строка/имя хоста.
- Команды создания таблицы, цепочки и правила NAT разделены для надёжного разбора аргументов.
- Убрана повторная генерация `ruter-route.service` в сценариях установки и восстановления.

## 2.0.1 — 2026-07-28

- Переписан генератор `ruter-route.sh`.
- Добавлена строгая проверка сетевых параметров до запуска.
- Исправлен порядок аргументов `ip rule`.
- Маршруты серверов VPN теперь извлекаются из outbound-конфигурации.
- nftables применяется одним атомарным блоком.
- При ошибке журнал показывает точную строку и команду.
- Удалена двойная генерация route-сервиса при обновлении подписки.
- Убран бесконечный автоперезапуск oneshot-сервиса.

## 2.0.0 — 2026-07-28

- Полный ребрендинг проекта в Ruter.
- Команда управления `ruter`.
- Новый сервис `ruter-route.service`.
- Новые пути `/etc/ruter` и `/usr/local/lib/ruter`.
- Удалены рабочие упоминания прежнего названия.
- Добавлены режимы маршрутизации для одного, нескольких или всех клиентов.
- Добавлено bypass-правило для самой VM.
- Добавлена диагностика `ruter doctor`.
- Добавлено безопасное самообновление.
