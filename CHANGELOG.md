# Changelog

## 2.0.0 — 2026-07-28

- Полный ребрендинг проекта в Ruter.
- Команда управления `ruter`.
- Новый сервис `ruter-route.service`.
- Новые пути `/etc/ruter` и `/usr/local/lib/ruter`.
- Удалены рабочие упоминания прежнего названия.
- Добавлены режимы маршрутизации для одного, нескольких или всех клиентов.
- Добавлено bypass-правило для самой VM.
- Добавлена диагностика `ruter doctor`.
- Добавлено безопасное самообновление.
